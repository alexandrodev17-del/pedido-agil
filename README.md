# PedidoÁgil

Sistema de gerenciamento de pedidos para lanchonetes e hamburguerias.

## Objetivo

O PedidoÁgil tem como objetivo facilitar o atendimento, o registro dos pedidos e a comunicação com a cozinha.

O projeto está sendo desenvolvido inicialmente em Java puro e futuramente será transformado em uma aplicação com Spring Boot.

## Funcionalidades planejadas

- Cadastro de produtos
- Exibição do cardápio
- Criação de pedidos
- Adição e remoção de itens
- Cálculo do valor total
- Envio dos pedidos para a cozinha
- Acompanhamento do status do pedido
- Formas de pagamento
- Promoções e cupons
- Programa de fidelidade
- Integração com WhatsApp
- Controle de estoque
- Suporte para pizzarias
